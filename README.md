# NaviPlayer Releases

This public repository is NaviPlayer's update and download channel.

Source changes are reviewed and built in the private development repository.
Successful Android, Windows, and Linux builds are published here so installed
clients can discover updates without embedding a GitHub credential.

## Downloads

Use the [Releases](../../releases) page:

- Android: `NaviPlayer-<version>.apk`
- Windows: `NaviPlayer-<version>.msi`
- Linux: `naviplayer_<version>_amd64.deb`

Debug-signed Android prereleases are intended for testing and are ignored by
the stable in-app updater.
